Cursor — hãng nổi tiếng với AI Code Editor và giờ đã chính thức thuộc về SpaceX — vừa ra mắt **Origin**, một nền tảng host code làm đúng những việc anh em vẫn dùng GitHub: làm việc chung trên codebase, duyệt và sửa code, xử lý pull request, lưu repo.

Thời điểm ra mắt mới là phần đáng nói. Origin lên sóng đúng ngày GitHub gặp sự cố toàn cầu, dịch vụ suy giảm suốt **hơn sáu tiếng** với tỷ lệ lỗi gần **20%** trên phạm vi thế giới. Và đây không phải lần đầu: theo phân tích của LeadDev, GitHub đã có **257 lần gián đoạn** trong vòng một năm qua, đủ để phóng viên Charles Humble mô tả là "một cuộc di cư thấy rõ của những người dùng tên tuổi".

## Không bắt anh em bỏ GitHub

Điểm khôn ngoan là Origin không đòi anh em dứt tình với GitHub. Hai bên chạy song song và chuyển code qua lại được.

> "Repo GitHub của bạn có thể nằm cạnh những repo Cursor host. Kết nối GitHub với Cursor, chọn tổ chức của bạn, và bạn sẽ thấy các repo có thể đồng bộ. Chọn một cái, Cursor sẽ kéo nó về."

Cursor cũng nói các tính năng "agent native" sẽ sớm có trên Origin nhưng chưa tiết lộ chi tiết, đồng thời đang dựng một hệ sinh thái ứng dụng rộng hơn quanh nền tảng này.

Dù vậy, đường còn xa. Theo số liệu của chính GitHub tính đến tháng 10 năm ngoái, nền tảng này có khoảng **180 triệu lập trình viên**. Ra đời năm 2007, được Microsoft mua lại, GitHub vẫn là nơi lưu trữ mã nguồn lớn nhất thế giới. Một tuần sập không xoá được gần hai thập kỷ thói quen.
